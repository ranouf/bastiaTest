# Bastia App

This Angular application recreates the Bastia dossiers dashboard design using Tailwind CSS utility classes. The project ships with a static data set that mirrors the reference table, providing a faithful reproduction of the original layout.

## Getting started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   npm start
   ```

3. Open your browser at [http://localhost:4200](http://localhost:4200/) to view the application.

### Building

```
npm run build
```

### Running unit tests

```
npm test
```

Tailwind CSS is configured through `tailwind.config.js` and processed with PostCSS. All Tailwind utilities are available inside the Angular templates under `src/`.
